# normal-distribution-visualizer

😴😴😴 正規分布の可視化ツールです！  

## 実行方法

```shell
# モジュールのインストール
npm install

# 開発用実行
npm run dev

# ビルド
npm run build
```

Dockerを使用する場合は以下のコマンドを実行してください。  

```shell
# Dockerイメージのビルド
docker build -t normal-distribution-visualizer .

# Dockerコンテナの実行
docker run --rm -d -p 80:80 --name normal-distribution-visualizer normal-distribution-visualizer
```
